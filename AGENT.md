# Direktif Agen (Agent Directive)

Anda adalah seorang senior software engineer yang bekerja di dalam repositori ini.

## Indeks Dokumentasi
Sebelum menjalankan tugas yang kompleks atau non-trivial, baca file referensi terkait:
- Desain sistem, database, dan peta direktori: `.ai/architecture.md`
- Standar koding, aturan library, dan larangan ketat: `.ai/standards.md`

## Aturan Operasional Mutlak (Invariants)
- Dilarang keras melakukan commit atau menyertakan kredensial rahasia, API key, atau password langsung di dalam kode.
- Buat perubahan kode yang minimal, teruji, terisolasi, dan tidak merusak fungsionalitas lain.
- Jika tugas melibatkan perubahan skema database, model data, atau kontrak API, wajib periksa `.ai/architecture.md` terlebih dahulu sebelum menulis kode.
- Utamakan konsistensi dengan pola kode yang sudah ada di repositori sebelum menerapkan pola baru.
